# C组 Web资源模糊测试字典生成工具使用说明

## 一、工具用途

本工具用于根据 B 组提供的目标词和 A 组提供的基线字典，生成 Web 资源模糊测试候选字典。

本工具只负责本地候选词生成和来源记录，不主动发送 HTTP 请求，也不负责判断候选路径是否真实存在。

## 二、输入文件

运行前需要将以下文件放在程序所在目录：

1. seeds.txt：B 组提供的目标词。
2. baseline_1000.txt：A 组提供的基线字典。
3. 词语来源表.xlsx：目标词的来源及证据记录。
4. 公开路径清单.xlsx：公开路径标记信息。

## 三、候选生成规则

1. 删除空行和首尾空格，删除完全重复项。
2. 保留目标词原始大小写，同时生成小写形式。
3. 纯英文词按照指定简单规则生成词形候选：
   - 不以 s 结尾的词追加 s。
   - 以 s 结尾且长度大于 3 的词删除末尾 s。
4. 保留 subdmain 原始拼写，并额外生成 subdomain 拼写纠错候选。
5. 默认生成 api/原词及 api/小写词形式。
6. 将生成候选与基线字典合并并去重，保留完整集合，不提前截断。
7. 公开路径只用于标记，不作为额外新发现候选。
8. 排除完整网址、绝对路径、含问号或井号、含 .. 路径段，以及 rate、limited 相关路径段。

说明：单复数规则属于简单启发式规则，不代表完整英语语法处理。

## 四、输出文件

1. generate_wordlist.py：字典生成程序。
2. candidates.txt：最终候选字典，可供 ffuf 读取。
3. 候选来源表.csv：记录候选、原始词、来源类别、扩展情况和使用规则等信息。同一候选有多种来源时保留多条记录。
4. 生成过程示例.txt：展示真实输入词的候选生成过程。
5. 使用说明.md：本文件。

## 五、运行方法

在工具所在目录打开 PowerShell，执行：

py -3 generate_wordlist.py

默认开启 api/ 前缀扩展。

如需关闭 API 前缀扩展，可执行：

py -3 generate_wordlist.py --no-api

## 七、注意事项

1. 候选词不代表对应路径真实存在。
2. 已公开路径不能计为新发现。
3. 不将 /cd/rate、rate 和 limited 相关路径加入候选。
4. 生成的候选集合不提前截断，由 D 组根据来源优先级进一步排序和选择测试范围。
5. 相同输入和相同运行参数应产生相同的候选结果。
6. 候选字典使用 UTF-8 编码，可供 ffuf 读取。
