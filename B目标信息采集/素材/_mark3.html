首页链接路径的片段拆分（/cd/* 与 /sub/* 两组）

红＝目录片段，蓝＝叶子片段；两种片段都作为目标词提取，完整路径另记入公开路径清单
#页面中的路径链接文字提取目标词
1 /cd/basic Basic Content Discovery cd + basic
2 /cd/recursion Content Discovery With Recursion cd + recursion
3 /cd/ext Content Discovery With File Extensions cd + ext
4 /cd/no404 No 404 Status cd + no404
5 /cd/param Param Mining cd + param
6 /cd/rate Rate Limited cd + rate （不进入候选）
7 /cd/pipes Pipes cd + pipes
8 /sub/vhost Virtual Host Discovery sub + vhost
注：第 6 行 /cd/rate 属限速练习，按统一边界排除，不提取为候选；
其余 7 条路径中的 cd、sub 为目录片段（复用出现 7 次 / 1 次），basic、recursion、ext、no404、param、pipes、vhost 为叶子片段。
