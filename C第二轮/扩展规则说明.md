# C组第二轮固定扩展规则

输入：baseline_1000.txt、seeds.txt、词语来源表-第二轮.xlsx。
脚本只生成字典文件，不发送 HTTP 请求。

## 对照字典
1. baseline_1000.txt：清洗后的基线字典。
2. baseline_plus_seeds.txt：基线在前，追加 B 组原始种子；只去重，不做词形、API 前缀或文件后缀扩展。
3. expanded_original.txt：按脚本原始生成顺序，先处理每个种子及其扩展，再追加基线字典。

## 扩展规则
1. 保留种子原词。
2. 生成小写形式（若与原词不同）。
3. 纯英文词按简单规则生成词形：不以 s 结尾追加 s；以 s 结尾且长度大于 3 删除末尾 s。
4. API 前缀：对原词及小写词生成 api/形式。
5. 文件后缀：对原词及小写词分别追加 .txt 和 .html。
6. 文件后缀规则仅作用于原词/小写词，不与单复数和 API 前缀进行组合，避免产生未约定的复合扩展。
7. 不允许空项、完整网址、绝对路径、含问号/井号/反斜杠、含 . 或 .. 路径段，以及 rate、limited 路径段。
8. 完全重复项按首次出现位置保留；来源表保留同一候选的不同来源记录。

## 边界
本脚本不读取 A 组冻结目标清单，不依据目标名称调整生成规则；不发送 HTTP 请求。公开路径清单由 E 组核验使用，不作为 C 组额外种子输入。
